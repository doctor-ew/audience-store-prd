
# MS-01.01: Foundational Setup (MVP)

> **Scope:** MVP | **Status:** To Do

## 1. Goal

To establish the foundational structure of the Next.js application, set up the development environment, and render a basic, non-interactive map centered on Mercedes-Benz Stadium. This milestone is critical for reducing technical risk by validating the core integration with the Google Maps API and Vercel deployment.

## 2. Work Breakdown & Files

| Task | Files to Create/Edit | Details |
| --- | --- | --- |
| **Project Initialization** | `package.json`, `pnpm-lock.yaml` | Initialize a new Next.js project using `pnpm`. Add essential dependencies like TypeScript, Tailwind CSS, and `@googlemaps/js-api-loader`. |
| **Basic Layout** | `app/layout.tsx`, `app/page.tsx` | Create the root layout and the main homepage component that will host the map. |
| **Map Component** | `components/Map.tsx` | Develop the initial `Map` component responsible for loading the Google Maps API and rendering the map canvas. |
| **API Key Management** | `.env.local`, `.gitignore` | Securely store the `GOOGLE_MAPS_API_KEY` in a local environment file and ensure it is ignored by Git. |
| **Unit Testing Setup** | `jest.config.js`, `tests/Map.test.tsx` | Configure Jest and React Testing Library. Add a basic unit test to ensure the `Map` component renders without crashing. |

## 3. Dependencies

- **Google Maps API Key:** A valid API key with the Maps JavaScript API enabled is required.
- **Vercel Account:** Access to a Vercel account for continuous deployment.

## 4. Acceptance Criteria

- [ ] **AC-Map-Display-1:** A user navigates to the homepage (`/`), and a map is rendered, centered on Mercedes-Benz Stadium (`33.754542, -84.402492`) within 2 seconds.
- [ ] **AC-Map-Display-2:** A user with location services disabled visits the site, and the map defaults to the stadium's coordinates without requesting location permissions.
- [ ] **AC-Security-1:** The Google Maps API key is not exposed on the client side and is loaded securely from environment variables.
- [ ] **AC-Deployment-1:** The application is successfully deployed to a Vercel preview environment.

## 5. Guardrails Checklist

- [ ] **Performance:** Initial page load (TTFB) is < 2 seconds.
- [ ] **Security:** `GOOGLE_MAPS_API_KEY` is stored server-side and not exposed in client-side code.
- [ ] **Code Quality:** Project is set up with `pnpm` and passes initial linting checks.
- [ ] **Testing:** The `Map.tsx` component has a basic rendering unit test.
