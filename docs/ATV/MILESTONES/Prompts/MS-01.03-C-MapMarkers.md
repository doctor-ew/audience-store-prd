# MS-01.03-C: Transit Marker Rendering (M.A.P.S Framework)

## Mission
Update `components/Map.tsx` to consume MARTA vehicle data from `useMartaData` hook and render custom bus/train markers at real-time locations on Google Maps.

**Core requirement:** Visually distinguish buses from trains, handle empty data gracefully, maintain performance with 50+ markers.

## Audience
- **End users:** Event attendees checking transit availability
- **Expect:** Icons update every 30 seconds showing vehicle movement

## Parameters

### Marker Icon Requirements
- Use lucide-react icons: `<Bus>` and `<Train>`
- Size: 32x32px for visibility at zoom level 15
- Colors: Orange for buses, blue for trains (MARTA brand)

### Google Maps Advanced Markers
Use `AdvancedMarkerElement` (modern API):
```typescript
import { Bus, Train } from 'lucide-react';
import { renderToString } from 'react-dom/server';

const iconHtml = renderToString(
  vehicle.type === 'bus'
    ? <Bus size={32} color="#FF6B00" />
    : <Train size={32} color="#0039A6" />
);

const marker = new google.maps.marker.AdvancedMarkerElement({
  map,
  position: { lat: vehicle.latitude, lng: vehicle.longitude },
  content: markerDiv,
  title: `${vehicle.type} - Route ${vehicle.route}`,
});
```

### Empty State Handling
Display "No transit data available" when:
- `vehicles` array is empty
- `isError` is true
- Message must be screen-reader accessible (aria-live="polite")
