# MS-01.03-A: MARTA GTFS-Realtime API Integration (M.A.P.S Framework)

## Mission
Build server-side API route (`/app/api/marta/route.ts`) that fetches real-time bus positions from MARTA's GTFS-Realtime feed and delivers vehicle location data in <2 seconds.

**Core requirement:** Use modern GTFS-Realtime API (no API key needed), with graceful fallback to mock data.

## Audience
- **Primary consumer:** `hooks/useMartaData.ts` (built in MS-01.03-B)
- **Expects:** JSON response with array of TransitVehicle objects
- **Needs:** <2s response, real-time bus data, reliable error handling

## Parameters

### ⚠️ IMPORTANT: Use GTFS-Realtime, Not REST API

**DO NOT USE the old REST API** - it's unreliable and slow:
- ❌ `https://developerservices.itsmarta.com/BRDRestService/RestBusRealTimeService/GetAllBus`
- ❌ Requires API key registration
- ❌ 75+ second timeouts or no response
- ❌ Frequently down

**USE GTFS-Realtime instead:**
- ✅ `https://gtfs-rt.itsmarta.com/TMGTFSRealTimeWebService/vehicle/vehiclepositions.pb`
- ✅ No API key required
- ✅ ~200ms response time
- ✅ Industry standard Protocol Buffers format
- ✅ 180-200 live bus positions

### MARTA GTFS-Realtime API
**Endpoint:** `https://gtfs-rt.itsmarta.com/TMGTFSRealTimeWebService/vehicle/vehiclepositions.pb`
- **Authentication:** None required
- **Method:** GET
- **Response:** Protocol Buffers (binary format)
- **Data:** 180-200 active bus positions across Atlanta
- **Update frequency:** Real-time (updates every few seconds)

**Implementation Example:**
```typescript
import { NextResponse } from "next/server";
import { TransitVehicle } from "@/lib/types";
import GtfsRealtimeBindings from "gtfs-realtime-bindings";

export async function GET() {
  const useMockData = process.env.USE_MOCK_MARTA_DATA === "true";

  if (useMockData) {
    return NextResponse.json({ vehicles: mockDataArray });
  }

  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), 10000);

  try {
    const response = await fetch(
      "https://gtfs-rt.itsmarta.com/TMGTFSRealTimeWebService/vehicle/vehiclepositions.pb",
      { signal: controller.signal }
    );

    clearTimeout(timeoutId);

    if (!response.ok) {
      return NextResponse.json({ vehicles: mockDataArray }); // Fallback
    }

    const buffer = await response.arrayBuffer();
    const feed = GtfsRealtimeBindings.transit_realtime.FeedMessage.decode(
      new Uint8Array(buffer)
    );

    const vehicles: TransitVehicle[] = feed.entity
      .filter((entity) => entity.vehicle?.position)
      .map((entity) => ({
        id: entity.vehicle!.vehicle?.id || entity.id,
        type: "bus" as const,
        latitude: entity.vehicle!.position!.latitude || 0,
        longitude: entity.vehicle!.position!.longitude || 0,
        route: entity.vehicle!.trip?.routeId || "Unknown",
      }))
      .filter((v) => v.latitude !== 0 && v.longitude !== 0);

    console.log(`Returning ${vehicles.length} valid bus positions`);
    return NextResponse.json({ vehicles });
  } catch (error) {
    console.error("GTFS-RT API error:", error);
    return NextResponse.json({ vehicles: mockDataArray }); // Fallback
  }
}
```
