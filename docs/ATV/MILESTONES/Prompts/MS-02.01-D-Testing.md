# MS-02.01-D: Bilingual Testing & Validation (P.R.O.M.P.T Framework)

## Problem
Components support English/Spanish (MS-02.01-C) but need comprehensive testing to ensure:
- Translation completeness (no English leakage)
- Accessibility compliance (WCAG 2.1 AA both languages)
- Layout stability (no breaks from longer Spanish)
- Persistence works (survives reload)

## Requirements
**Must verify:**
- All UI strings translated (100% coverage)
- WCAG 2.1 AA in both English and Spanish
- Language preference persists
- Screen readers work in both languages
- No layout breaks/truncation in Spanish

## Methods

### 1. Automated Tests

**Translation coverage test:**
```typescript
// tests/i18n/translation-coverage.test.ts
it('Spanish has all English keys', () => {
  const enKeys = flattenKeys(enTranslations);
  const esKeys = flattenKeys(esTranslations);
  enKeys.forEach(key => expect(esKeys).toContain(key));
});
```

**Component translation test:**
```typescript
// tests/components/bilingual.test.tsx
it('TrafficToggle renders in Spanish', async () => {
  await i18n.changeLanguage('es');
  render(<TrafficToggle />);
  expect(screen.getByText('Alternar Tráfico')).toBeInTheDocument();
});
```

**Persistence test:**
```typescript
it('saves language to localStorage', async () => {
  await i18n.changeLanguage('es');
  expect(localStorage.getItem('i18nextLng')).toBe('es');
});
```

### 2. Accessibility Audits

**Lighthouse audit:**
```bash
# Run in both languages
lighthouse http://localhost:3000 --only-categories=accessibility --output=json

# Verify score = 100 for both
```

**Axe DevTools checklist:**
- [ ] English mode: 0 violations
- [ ] Spanish mode: 0 violations
- [ ] Color contrast: 3:1 UI, 4.5:1 text
- [ ] Keyboard navigation works identically

### 3. Screen Reader Testing

**Test protocol:**
1. NVDA/VoiceOver with English selected
2. Tab to TrafficToggle → verify English announcement
3. Switch to Spanish
4. Tab to TrafficToggle → verify Spanish announcement
5. Verify HTML lang attribute matches (`<html lang="es">`)

### 4. Visual Regression

**Layout stability:**
- [ ] Load at 320px width: No horizontal scroll (both languages)
- [ ] Load at 768px width: Header layout intact
- [ ] Load at 1920px width: No excessive whitespace
- [ ] Button heights consistent across languages
