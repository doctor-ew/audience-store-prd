# MS-03.01-B: Firebase Project Setup (D.E.C.I.D.E - Execute)

## Objective
Provision Firebase project, configure Firestore, set up security rules, integrate Firebase Admin SDK with Vercel.

**Core requirement:** Firestore accessible only via server-side API routes.

## Steps

### 1. Create Firebase Project
1. Go to console.firebase.google.com
2. Create project: `atlanta-fifa-navigator`
3. Enable Firestore in production mode, region: `us-central1`

### 2. Configure Security Rules
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Deny all client access (server-side only)
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

### 3. Generate Service Account Key
1. Project Settings → Service accounts → Generate new private key
2. Download JSON file
3. **Never commit to git**

### 4. Configure Environment
**Local (`.env.local`):**
```
FIREBASE_SERVICE_ACCOUNT_KEY='{"type":"service_account","project_id":"..."}'
```

**Stringify JSON:** `cat key.json | tr -d '\n'`

**Vercel:** Add `FIREBASE_SERVICE_ACCOUNT_KEY` environment variable in dashboard

### 5. Install Firebase Admin SDK
```bash
pnpm add firebase-admin
```

### 6. Create Initialization Module
**File: `lib/firebase.ts`**
```typescript
import { initializeApp, getApps, cert } from 'firebase-admin/app';
import { getFirestore } from 'firebase-admin/firestore';

export function initializeFirebase() {
  if (getApps().length === 0) {
    const serviceAccount = JSON.parse(
      process.env.FIREBASE_SERVICE_ACCOUNT_KEY || '{}'
    );
    initializeApp({ credential: cert(serviceAccount) });
  }
  return getFirestore();
}
```

### 7. Test Connection
Create `scripts/test-firebase.ts`:
- Initialize Firebase
- Write test document
- Read document
- Delete document
- Run: `pnpm tsx scripts/test-firebase.ts`
