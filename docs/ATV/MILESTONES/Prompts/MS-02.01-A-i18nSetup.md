# MS-02.01-A: i18n Infrastructure Setup (P.R.O.M.P.T Framework)

## Problem
Atlanta FIFA Navigator hardcodes all UI strings in English, excluding Spanish-speaking users (13% of Atlanta).

**Goal:** Configure i18next with English/Spanish translation files before building switcher or translating components.

## Requirements
**Must-haves:**
- i18next + react-i18next configured in Next.js 15+
- Translation files for English (en) and Spanish (es)
- Auto language detection: localStorage → browser language → fallback to English
- Type-safe translation keys (TypeScript autocomplete)

**Must-NOTs:**
- Do NOT translate components yet (MS-02.01-C handles that)
- Do NOT add languages beyond en/es

## Methods

### Step 1: Install Dependencies
```bash
pnpm add i18next react-i18next i18next-browser-languagedetector
```

### Step 2: Create i18n Configuration
**File: `lib/i18n.ts`**
```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: require('@/public/locales/en/common.json') },
      es: { translation: require('@/public/locales/es/common.json') },
    },
    fallbackLng: 'en',
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },
  });
```

### Step 3: Create Translation Files
**Directory:** `public/locales/{en,es}/common.json`

```json
// en/common.json
{
  "app": { "title": "Atlanta FIFA Navigator" },
  "map": {
    "loading": "Loading map...",
    "toggleTraffic": "Toggle Traffic",
    "toggleTrafficAriaLabel": "Toggle traffic layer visibility"
  },
  "transit": {
    "loading": "Loading transit data...",
    "noData": "No transit data available"
  }
}

// es/common.json (translate all keys)
{
  "app": { "title": "Navegador FIFA Atlanta" },
  "map": {
    "loading": "Cargando mapa...",
    "toggleTraffic": "Alternar Tráfico",
    "toggleTrafficAriaLabel": "Alternar visibilidad de capa de tráfico"
  }
  // ... Spanish translations
}
```

### Step 4: Update Root Layout
**File: `app/layout.tsx`**
```typescript
import '@/lib/i18n'; // Initialize i18n

export default function RootLayout({ children }) {
  return (
    <html lang="en"> {/* Updated dynamically by LanguageSwitcher */}
      <body>{children}</body>
    </html>
  );
}
```

## Parameters

**Translation key naming:**
- Use dot notation: `category.subcategory.key`
- Categories: `app`, `map`, `transit`, `errors`
- camelCase for multi-word keys: `toggleTraffic`, `noData`

**Translation quality:**
- Spanish reviewed by native speaker (not Google Translate alone)
- Use MARTA's official Spanish terms

## Success Criteria

- [ ] i18next configured in `lib/i18n.ts`
- [ ] English translations in `public/locales/en/common.json`
- [ ] Spanish translations in `public/locales/es/common.json`
- [ ] Root layout imports i18n config
- [ ] Manual test: Console `i18n.changeLanguage('es')` → `i18n.t('map.loading')` returns "Cargando mapa..."
