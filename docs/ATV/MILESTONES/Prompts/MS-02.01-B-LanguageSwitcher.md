# MS-02.01-B: Language Switcher Component (P.R.O.M.P.T Framework)

## Problem
Users need visible UI control to switch between English and Spanish. i18n infrastructure exists (MS-02.01-A) but has no user-facing interface.

## Requirements
**Must-haves:**
- Button accessible from all pages (persistent in header)
- Shows current language (EN or ES)
- Clicking toggles between languages
- Keyboard accessible (Tab, Space/Enter)
- Updates HTML `lang` attribute (for screen readers)
- Persists to localStorage (i18next handles automatically)

**Must-NOTs:**
- Do NOT add dropdown for >2 languages (toggle sufficient)
- Do NOT use flags (accessibility issue)

## Methods

**File: `components/LanguageSwitcher.tsx`**
```typescript
'use client';

import { useTranslation } from 'react-i18next';
import { Globe } from 'lucide-react';
import { useEffect } from 'react';

export function LanguageSwitcher() {
  const { i18n } = useTranslation();

  useEffect(() => {
    document.documentElement.lang = i18n.language;
  }, [i18n.language]);

  const toggleLanguage = () => {
    const newLang = i18n.language === 'en' ? 'es' : 'en';
    i18n.changeLanguage(newLang);
  };

  return (
    <button
      onClick={toggleLanguage}
      aria-label={`Switch to ${i18n.language === 'en' ? 'Spanish' : 'English'}`}
      className="flex items-center gap-2 px-4 py-2 bg-white border rounded-lg hover:bg-gray-50 focus:ring-2 focus:ring-blue-500"
    >
      <Globe size={20} aria-hidden="true" />
      <span>{i18n.language.toUpperCase()}</span>
    </button>
  );
}
```

**Integrate into layout:**
```typescript
// app/layout.tsx
import { LanguageSwitcher } from '@/components/LanguageSwitcher';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <header>
          <h1>Atlanta FIFA Navigator</h1>
          <LanguageSwitcher />
        </header>
        <main>{children}</main>
      </body>
    </html>
  );
}
```

## Parameters

**Accessibility (WCAG 2.1 AA):**
- Keyboard: Button focusable, operable via Space/Enter
- Focus indicator: Visible outline (3:1 contrast)
- Touch target: Minimum 44x44px
- ARIA label: Descriptive ("Switch to Spanish")
- Screen reader: Announces language change
