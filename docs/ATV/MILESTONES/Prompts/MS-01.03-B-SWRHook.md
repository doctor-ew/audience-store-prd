# MS-01.03-B: MARTA Data Fetching Hook (M.A.P.S Framework)

## Mission
Build custom SWR hook (`hooks/useMartaData.ts`) that fetches transit data from `/api/marta`, auto-refreshes every 30 seconds, and exposes loading/error states.

**Core requirement:** Enable real-time transit updates without manual polling.

## Audience
- **Primary consumer:** `components/Map.tsx` (built in MS-01.03-C)
- **Expects:** Typed TransitVehicle array, isLoading, isError booleans
- **Needs:** Automatic 30-second refresh, retry logic on failures

## Parameters

### SWR Configuration
Install dependency:
```bash
pnpm add swr
```

**Hook requirements:**
- Fetch from `/api/marta` endpoint
- Refresh interval: 30 seconds
- Retry strategy: 3 attempts with exponential backoff
- Dedupe multiple hook instances (share single fetch)

### Type Definitions
```typescript
import type { TransitVehicle } from '@/app/api/marta/route';

interface UseMartaDataReturn {
  vehicles: TransitVehicle[] | undefined;
  isLoading: boolean;
  isError: boolean;
  error: Error | undefined;
}
```

## Success Criteria

**Hook implementation structure:**
```typescript
import useSWR from 'swr';

const fetcher = async (url: string) => {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`API error: ${res.status}`);
  return res.json();
};

export function useMartaData(): UseMartaDataReturn {
  const { data, error, isLoading } = useSWR('/api/marta', fetcher, {
    refreshInterval: 30000,
    revalidateOnFocus: false,
    revalidateOnReconnect: true,
    dedupingInterval: 5000,
    errorRetryCount: 3,
  });

  return {
    vehicles: data?.vehicles,
    isLoading,
    isError: !!error,
    error,
  };
}
```

**Functional requirements:**
- [ ] Hook fetches data on mount
- [ ] Returns typed TransitVehicle array
- [ ] Auto-refetches every 30 seconds
- [ ] Retries 3 times on error
- [ ] Exposes loading/error states
- [ ] Multiple instances share SWR cache
