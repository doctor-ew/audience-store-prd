# MS-03.01-D: Preferences API Routes (D.E.C.I.D.E - Execute)

## Objective
Build `/api/preferences` with GET and POST handlers to read/write user preferences, achieving <500ms P95 latency.

**Core requirement:** API route is ONLY interface to Firestore—client never accesses database directly.

## API Specification

**GET /api/preferences?userId={uuid}**
- Success (200): Returns UserPreferenceResponse JSON
- Not found (404): `{ "error": "User not found" }`
- Bad request (400): `{ "error": "Missing userId parameter" }`

**POST /api/preferences**
- Body: `{ userId, language, favorites }`
- Success (200): Returns created/updated preference
- Validation error (400): `{ "error": "Invalid request body", "details": [...] }`

## Implementation

**File: `app/api/preferences/route.ts`**
```typescript
import { NextRequest, NextResponse } from 'next/server';
import { getUserPreference, setUserPreference } from '@/lib/user-preferences';
import { UserPreferenceInputSchema } from '@/lib/schemas/user-preference.schema';
import { ZodError } from 'zod';

export async function GET(request: NextRequest) {
  const userId = request.nextUrl.searchParams.get('userId');

  if (!userId) {
    return NextResponse.json({ error: 'Missing userId' }, { status: 400 });
  }

  const preference = await getUserPreference(userId);

  if (!preference) {
    return NextResponse.json({ error: 'User not found' }, { status: 404 });
  }

  return NextResponse.json(preference);
}

export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    const validated = UserPreferenceInputSchema.parse(body);
    const result = await setUserPreference(validated);

    return NextResponse.json(result);
  } catch (error) {
    if (error instanceof ZodError) {
      return NextResponse.json(
        { error: 'Invalid request body', details: error.errors },
        { status: 400 }
      );
    }

    return NextResponse.json(
      { error: 'Internal server error' },
      { status: 500 }
    );
  }
}
```

## Performance
- Target: <500ms P95 latency
- Typical: 150-200ms (Firestore + Next.js overhead)
- Add `Cache-Control: private, max-age=60` for GET responses
