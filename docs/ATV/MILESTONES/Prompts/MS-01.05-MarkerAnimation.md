# MS-01.05: Smooth Transit Marker Animation (M.A.P.S Framework)

## Mission
Implement smooth, real-time animation for transit markers (buses and trains) on the Google Map, transitioning them between position updates every 10 seconds without jarring jumps.

**Core requirement:** Reuse existing marker instances and animate position changes using `requestAnimationFrame` with easing, instead of destroying and recreating markers.

## Implementation Pattern

### Anti-Pattern: Destroying and Recreating Markers
```typescript
// ❌ WRONG: This causes jarring jumps and flicker
useEffect(() => {
  // Clear ALL markers
  markers.forEach(marker => marker.map = null);

  // Create ALL new markers
  const newMarkers = vehicles.map(vehicle => {
    return new google.maps.marker.AdvancedMarkerElement({
      map,
      position: { lat: vehicle.latitude, lng: vehicle.longitude },
      // ...
    });
  });

  setMarkers(newMarkers);
}, [vehicles]);
```

**Why this fails:**
- Destroys all markers every 10 seconds
- Creates all new markers from scratch
- Position "jumps" instantly to new location
- Causes visual flicker
- Poor performance (constant DOM manipulation)

### Correct Pattern: Persistent Markers with Animation

```typescript
// ✅ CORRECT: Reuse markers, animate position changes
const markersRef = useRef<Map<string, google.maps.marker.AdvancedMarkerElement>>(new Map());

useEffect(() => {
  if (!map || !vehicles) return;

  const existingMarkers = markersRef.current;
  const currentVehicleIds = new Set(vehicles.map(v => v.id));

  // 1. Remove markers for vehicles that no longer exist
  existingMarkers.forEach((marker, id) => {
    if (!currentVehicleIds.has(id)) {
      marker.map = null;
      existingMarkers.delete(id);
    }
  });

  // 2. Update or create markers for each vehicle
  vehicles.forEach((vehicle) => {
    const existingMarker = existingMarkers.get(vehicle.id);
    const newPosition = { lat: vehicle.latitude, lng: vehicle.longitude };

    if (existingMarker) {
      // ANIMATE existing marker to new position
      animateMarker(existingMarker, newPosition);
    } else {
      // CREATE new marker (vehicle just appeared)
      const iconHtml = renderToString(
        vehicle.type === "bus"
          ? <Bus size={32} color="#FF6B00" strokeWidth={2} />
          : <Train size={32} color="#0066CC" strokeWidth={2} />
      );

      const markerDiv = document.createElement("div");
      markerDiv.innerHTML = iconHtml;

      const newMarker = new google.maps.marker.AdvancedMarkerElement({
        map,
        position: newPosition,
        content: markerDiv,
        title: `${vehicle.type === "bus" ? "Bus" : "Train"} - Route ${vehicle.route}`,
      });

      existingMarkers.set(vehicle.id, newMarker);
    }
  });
}, [map, vehicles]);
```

### Animation Function

```typescript
const animateMarker = (
  marker: google.maps.marker.AdvancedMarkerElement,
  newPosition: google.maps.LatLngLiteral
) => {
  const currentPos = marker.position as google.maps.LatLngLiteral;
  if (!currentPos) {
    marker.position = newPosition;
    return;
  }

  const startLat = currentPos.lat;
  const startLng = currentPos.lng;
  const endLat = newPosition.lat;
  const endLng = newPosition.lng;

  const duration = 1000; // 1 second animation
  const startTime = performance.now();

  const animate = (currentTime: number) => {
    const elapsed = currentTime - startTime;
    const progress = Math.min(elapsed / duration, 1);

    // Easing function for smooth animation (ease-in-out cubic)
    const easeProgress = progress < 0.5
      ? 2 * progress * progress
      : 1 - Math.pow(-2 * progress + 2, 2) / 2;

    const lat = startLat + (endLat - startLat) * easeProgress;
    const lng = startLng + (endLng - startLng) * easeProgress;

    marker.position = { lat, lng };

    if (progress < 1) {
      requestAnimationFrame(animate);
    }
  };

  requestAnimationFrame(animate);
};
```

## Key Implementation Details

### 1. Persistent Marker Storage
```typescript
const markersRef = useRef<Map<string, google.maps.marker.AdvancedMarkerElement>>(new Map());
```

**Why Map instead of Array?**
- O(1) lookup by vehicle ID
- Easy to check if marker exists
- Simple to delete specific markers

**Why useRef instead of useState?**
- No need to trigger re-renders when markers update
- Direct mutation is safe (not part of React state)
- Persists across renders without causing re-renders

### 2. Three Update Operations

**a) Remove disappeared vehicles:**
```typescript
existingMarkers.forEach((marker, id) => {
  if (!currentVehicleIds.has(id)) {
    marker.map = null; // Remove from map
    existingMarkers.delete(id); // Remove from tracking
  }
});
```

**b) Animate existing vehicles:**
```typescript
if (existingMarker) {
  animateMarker(existingMarker, newPosition);
}
```

**c) Create new vehicles:**
```typescript
else {
  const newMarker = new google.maps.marker.AdvancedMarkerElement({...});
  existingMarkers.set(vehicle.id, newMarker);
}
```

### 3. Easing Function Explained

**Linear animation (no easing):**
```
Speed: |--------|--------|--------|
       constant speed throughout
```

**Ease-in-out (our implementation):**
```
Speed: |-----|---------|--------|---|
       slow  faster    faster   slow
       start           middle   end
```

**Formula:**
```typescript
// First half: accelerate (ease-in)
if (progress < 0.5) {
  easeProgress = 2 * progress * progress;
}
// Second half: decelerate (ease-out)
else {
  easeProgress = 1 - Math.pow(-2 * progress + 2, 2) / 2;
}
```

**Visual effect:** Natural motion that mimics real-world physics

### 4. requestAnimationFrame vs setInterval

**Why requestAnimationFrame?**
- Syncs with browser's repaint cycle (60fps)
- Pauses when tab is inactive (saves CPU)
- Sub-millisecond precision
- Smoother animation than setInterval

**setInterval problems:**
- Not synced with screen refresh
- Continues when tab inactive
- Less precise timing
- Can cause jank

## Common Issues and Solutions

### Issue: Markers jumping instead of animating
**Symptom:** Instant position changes every 10 seconds

**Cause:** Not calling `animateMarker()` or using direct position assignment

**Fix:** Ensure this line exists:
```typescript
if (existingMarker) {
  animateMarker(existingMarker, newPosition); // ✅
  // NOT: existingMarker.position = newPosition; // ❌
}
```

### Issue: All markers recreated on every update
**Symptom:** Flicker every 10 seconds, console shows "Creating X new markers" repeatedly

**Cause:** Not using `useRef`, or using `useState` (causes re-render and loss of reference)

**Fix:** Use `useRef` for marker storage:
```typescript
const markersRef = useRef<Map<...>>(new Map()); // ✅
// NOT: const [markers, setMarkers] = useState(...); // ❌
```

### Issue: Duplicate markers (overlapping icons)
**Symptom:** Multiple bus/train icons at same location

**Cause:** Not removing old markers before creating new ones

**Fix:** Ensure cleanup code runs:
```typescript
existingMarkers.forEach((marker, id) => {
  if (!currentVehicleIds.has(id)) {
    marker.map = null; // ✅ MUST remove from map
    existingMarkers.delete(id);
  }
});
```

### Issue: Animation is choppy
**Symptom:** Stuttering movement instead of smooth glide

**Possible causes:**
1. Browser tab throttled (tab not focused)
2. Too many markers (performance issue)
3. Not using `requestAnimationFrame`

**Debugging:**
```typescript
const animate = (currentTime: number) => {
  console.log(`Frame: ${Math.round(progress * 100)}%`);
  // Should see: 0%, 2%, 4%, ..., 98%, 100% at ~60fps
  // If you see: 0%, 20%, 40%, 80%, 100% → choppy!
};
```

## Performance Considerations

### Marker Instance Reuse
- **Creating 200 markers:** ~50-100ms
- **Animating 200 markers:** ~1-5ms per frame
- **Savings:** 200 markers × 6 updates/min = avoiding 1200 marker creations/min

### Animation Performance
- **Duration:** 1 second
- **Frame rate:** 60fps
- **Frames per animation:** ~60 frames
- **CPU time per frame:** <1ms (highly efficient)

### Memory Usage
- **Marker instance:** ~1-2 KB each
- **200 markers:** ~200-400 KB
- **Animation frames:** Negligible (just number updates)

## Advanced: Custom Easing Functions

Want different animation feel? Try these:

**Linear (no easing):**
```typescript
const easeProgress = progress;
```

**Ease-in (accelerate):**
```typescript
const easeProgress = progress * progress;
```

**Ease-out (decelerate):**
```typescript
const easeProgress = 1 - (1 - progress) * (1 - progress);
```

**Ease-in-out (current implementation):**
```typescript
const easeProgress = progress < 0.5
  ? 2 * progress * progress
  : 1 - Math.pow(-2 * progress + 2, 2) / 2;
```

**Bounce (playful):**
```typescript
const easeProgress = 1 - Math.abs(Math.sin(progress * Math.PI * 2.5));
```
