
# MS-01.03: Transit Overlay (MVP)

> **Scope:** MVP | **Status:** To Do

## 1. Goal

To integrate real-time MARTA transit data into the application by creating a backend proxy and displaying bus and train locations on the map. This is a core feature that provides significant value to users relying on public transportation.

## 2. Work Breakdown & Files

| Task | Files to Create/Edit | Details |
| --- | --- | --- |
| **MARTA API Proxy** | `app/api/marta/route.ts` | Create a Next.js API route to act as a secure proxy for the MARTA API. This route will fetch data server-side to protect the MARTA API key. |
| **Data Fetching Hook** | `hooks/useMartaData.ts` | Implement a custom SWR hook to fetch transit data from the internal `/api/marta` endpoint, providing client-side caching and revalidation. |
| **Map Marker Rendering** | `components/Map.tsx` | Update the `Map` component to consume the data from the SWR hook and render custom markers for each bus and train. |
| **Integration Testing** | `tests/api/marta.test.ts` | Add an integration test for the `/api/marta` route to ensure it correctly fetches data from the MARTA API and handles errors gracefully. |
| **Unit Testing** | `tests/hooks/useMartaData.test.tsx` | Add unit tests for the SWR hook to verify its data fetching and state management logic. |

## 3. Dependencies

- **MS-01.02-map_rendering:** Completion of the core map rendering.
- **MARTA API Key:** A valid API key for the MARTA real-time data feed.

## 4. Acceptance Criteria

- [ ] **AC-MARTA-API-1:** The `/api/marta` endpoint successfully proxies requests and returns a valid JSON payload from the MARTA API in < 500 ms.
- [ ] **AC-MARTA-API-2:** The `/api/marta` endpoint gracefully handles upstream API failures by returning a `503` status.
- [ ] **AC-Transit-Viz-1:** Bus and train icons are displayed on the map at their correct real-time locations.
- [ ] **AC-Transit-Viz-2:** If the MARTA API returns no vehicles, the UI displays a "No transit data available" message.

## 5. Guardrails Checklist

- [ ] **Performance:** API route latency is < 500 ms.
- [ ] **Security:** The MARTA API key is stored server-side and is not exposed to the client.
- [ ] **Reliability:** The application handles MARTA API downtime gracefully, as per the fallback behavior defined in `Guardrails.md`.
- [ ] **Testing:** The `/api/marta` route has an integration test, and the `useMartaData` hook has unit tests.
