
# MS-02.01: User Experience Polish (Stretch)

> **Scope:** Stretch | **Status:** To Do

## 1. Goal

To enhance the user experience by adding bilingual (English/Spanish) support and a mechanism for saving user preferences. This milestone focuses on accessibility and personalization, directly addressing key PRD success metrics.

## 2. Work Breakdown & Files

| Task | Files to Create/Edit | Details |
| --- | --- | --- |
| **i18n Configuration** | `i18n.js`, `public/locales/` | Set up `i18next` and `react-i18next`. Create JSON translation files for English (`en`) and Spanish (`es`). |
| **Language Switcher UI** | `components/LanguageSwitcher.tsx` | Create a dropdown or button component that allows users to switch the application's language. |
| **Preference Management** | `store/usePreferences.ts` | Implement a React Context or similar state management solution to handle user preferences, starting with language. Initially, persist to local storage. |
| **Component Integration** | `app/layout.tsx`, `components/*.tsx` | Integrate the translation functions (`useTranslation` hook) into all UI components with text. |
| **Unit Testing** | `tests/LanguageSwitcher.test.tsx` | Add unit tests for the `LanguageSwitcher` to ensure it correctly changes the language and updates the UI. |

## 3. Dependencies

- **MS-01.03-transit_overlay:** Completion of all MVP milestones.

## 4. Acceptance Criteria

- [ ] **AC-Bilingual-1:** A user can switch between English and Spanish, and all UI text updates immediately without a page reload.
- [ ] **AC-Bilingual-2:** The user's language preference is saved to local storage and is automatically applied on their next visit.
- [ ] **AC-Accessibility-1:** The `LanguageSwitcher` is fully keyboard-accessible.

## 5. Guardrails Checklist

- [ ] **Accessibility:** The application remains compliant with WCAG 2.1 AA standards in both languages.
- [ ] **Performance:** Loading translation files does not significantly impact initial page load speed.
- [ ] **Code Quality:** i18n implementation follows best practices for code splitting and lazy loading locales.
- [ ] **Testing:** The `LanguageSwitcher` component is unit tested.
